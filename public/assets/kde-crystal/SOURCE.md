# KDE Crystal toolbar icons

The toolbar PNGs in this folder come from the classic CrystalSVG icon theme,
using its native 22×22 artwork. Source archive:

https://github.com/MartinF99/crystalSVG-plasma5

The app uses the theme's search, hardware monitor, network, folder, Konsole,
Amarok queue/playback, transfer-arrow, JuK, and media transport artwork at the
original 16×16, 22×22, and 32×32 sizes.
